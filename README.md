# HSK1 Тренажёр 中文

Веб-приложение для изучения 300 слов уровня HSK1.

## Функции

- **Карточки** — переворачиваемые карточки с иероглифом, пинь-инем, значением и примером
- **Тест** — 4 варианта ответа, 3 режима (иероглиф→значение, значение→иероглиф, пинь-инь→иероглиф)
- **Словарь** — все 300 слов с поиском и фильтрами
- **Озвучка** — браузерный TTS для китайского языка
- **Spaced Repetition** — умный режим повторения трудных слов
- **Прогресс** — отслеживание статуса каждого слова и стрик дней

## Запуск

```bash
npm install
npm run dev
```

## Технологии

- Next.js 16 + TypeScript
- Tailwind CSS
- localStorage для хранения прогресса
